# Code of conduct

All participants in VeilGate's issue tracker, reviews, and discussions are
expected to communicate respectfully and constructively.

- Discuss technical ideas and observed behavior without personal attacks.
- Do not harass, threaten, discriminate against, or disclose private information
  about other people.
- Respect requests to stop unwelcome interactions.
- Report suspected security vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md), without publishing sensitive reproductions.

The repository maintainers may moderate or remove content and restrict
participation when these expectations are violated. Report conduct concerns
privately to a maintainer through a communication channel listed on the
maintainer's verified GitHub profile; do not post private information publicly.
